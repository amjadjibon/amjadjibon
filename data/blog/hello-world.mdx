After years of building systems at work and tinkering with side projects in my spare time, I finally
decided to start writing things down. This is that place.

## Who I Am

I'm Amjad — a software engineer based in Kuala Lumpur, Malaysia. I've spent the last 7+ years building
distributed systems, microservices, and cloud infrastructure, mostly in **Go** and **Python**.
My day job is as a Senior Technical Consultant at Arvato Systems, where I work on everything from
API design to Kubernetes deployments to AI automation pipelines.

Before that I was at UPAY (a Bangladeshi fintech), where I re-engineered a set of Python microservices
into Go and saw a 35% throughput improvement and 50% memory reduction. That migration cemented my
appreciation for Go as a backend language.

## What I'll Write About

Mostly backend engineering — the kind of things I wish were better documented when I was learning:

- **Go patterns** for production microservices: error handling, concurrency, testing strategies
- **Kubernetes** operations: real-world tips beyond what the official docs cover
- **Distributed systems** fundamentals: consensus, replication, failure modes (my [raftd](https://github.com/amjadjibon/raftd) project is my playground here)
- **AI engineering**: using LangChain and LangGraph to build practical automation — not just demos
- **Career reflections**: going from Bangladesh to Malaysia, from Python to Go, from engineer to consultant

## Side Projects

A few things I've built that might show up as blog topics:

- [**htemplx**](https://github.com/amjadjibon/htemplx) — A full-stack Go starter using HTMX and Templ. My counterargument to JavaScript fatigue.
- [**raftd**](https://github.com/amjadjibon/raftd) — A distributed key-value store built on the Raft consensus algorithm.
- [**termchess**](https://github.com/amjadjibon/termchess) — Chess in the terminal, built with Bubble Tea. Because why not.
